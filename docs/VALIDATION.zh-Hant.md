# 0.1 開發預覽驗證紀錄

日期：2026-11-03。測試主機為 Apple Silicon、macOS 27；使用 Xcode 27.0 / Swift 6.4，部署目標 macOS 14。部署目標不代表已在 macOS 14 真機測試。

## 已執行

- Swift Debug / Release 編譯：App、InputMethodKit 可執行檔、核心檢查工具皆可建置。
- 14 個 XCTest 測試方法：字典載入、6 組基本中文正例、21 組其他詞彙的前六候選涵蓋、26 組英文／代碼反例、混合文字／空白／標點保留、缺失資料 fail-open、輸入上限、實體鍵位、組字與復原。
- 隨機狀態機測試：固定 seed，200 組各 80 次輸入／退格事件，Esc 後比對原始按鍵；不是長期或任意事件序列的形式證明。
- 原生 App 真實按鍵：標準注音系統輸入來源啟用時，`su3cl3` 顯示「你好」；↓ 換成「妳好」；Esc 還原 `su3cl3`。
- 原生 App 真實按鍵：第一次 Enter 提交文字，第二次 Enter 才在測試文字框換行。
- 原生 App 真實按鍵：`python3 k8s` 保留英文與代碼；純英文模式輸出 `su3cl3`。
- App 還原頁：包含中文、`hk4g4`、`su3cl3`、`5j/ eji6`、英文與代碼的混合文字，確認輸出「測試」「你好」「中國」，並保留英文、換行與代碼。
- 三個頁面的原生視窗截圖檢查；安裝頁顯示「尚未安裝系統輸入法」。
- 上游詞庫來源固定：171,126 筆，來源與產生檔 SHA-256 比對。
- App 與內附輸入法 ad-hoc 簽章完整性檢查；DMG 建立與映像 checksum 驗證。
- 將最終 DMG 唯讀掛載，22 個 App 檔案逐一 SHA-256 與建置產物相等；直接從掛載 App 執行 `--self-check`，載入 171,126 筆內附詞庫並通過中英樣例。
- 從最終 DMG 的 App 開啟原生視窗，以實際按鍵確認「你好」；測試非同步還原結果，以及切頁返回後仍保留文字。

## 效能抽樣

`ShunTypeCheck` 使用 13 個固定字串 × 30 輪，總共 390 次。一次 Release 抽樣結果：

| 指標 | 結果 |
|---|---:|
| 冷啟動詞庫載入 | 約 651 ms |
| 暖機核心解碼 p50 | 約 0.004 ms |
| 暖機核心解碼 p95 | 約 0.024 ms |
| 暖機核心解碼最大值 | 約 0.470 ms |

這是短字串、單一主機的核心運算抽樣，不包含 OS 事件派送、App 渲染、跨 App 呼叫、輸入法啟動或實際按鍵到畫面延遲。不是準確率、極端延遲或產品優越性證明。測試清單也包含刻意保留原文的 first-tone 例子。

- 未完成 LINE、Word、Safari、Chrome、VS Code、終端機等跨 App 接受測試。
- 未測 App 特有的復原、選取、直排、遠端桌面、安全輸入、睡眠喚醒與多視窗焦點切換。

## 後續發布門檻

先取得使用者對試打手感的回饋，再在明確選定的測試帳號／機器啟用 IMK。確認中文、英文、選字、退格、Esc、Enter、原生復原與焦點切換後，才逐 App 擴大測試。完成 Developer ID、公證、安裝／升級／移除與多機驗證後，才以穩定版對一般使用者推薦。
